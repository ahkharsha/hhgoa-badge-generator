# HH Goa 2026 Frame & ID Generator

Create instant branded HH Goa 2026 PFP frames, Builder ID badges, and squad passes with AI builder titles and 1-click sharing to X (#FrameInGoa).

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Build For Deploy

1. Build the client and server bundle:
   `npm run build`
2. Start the production server:
   `npm run start`
